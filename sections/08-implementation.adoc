== Implementation Walkthrough

=== Alex's 8 principles

Every PR had to satisfy these. Violating any of them was cause for rejection, regardless of how well the code compiled.

1. No manual JSON de/serialization in services — services take typed request DTOs.
2. No `context.authenticatedUser()` in business logic — authorization at URL level via `SecurityConfig`.
3. Handlers return typed `XxxResponse` POJOs, not `CommandProcessingResult`.
4. No new `CommandWrapperBuilder` additions — the goal is to delete them.
5. `SecurityConfig` entries at the end of the chain, right before the `twofactor` block.
6. No trivial `@ApiResponse(200)` annotations.
7. Legacy `xxxService(JsonCommand)` methods must be *deleted*, not kept alongside.
8. No `HashMap` regression in integration tests — use typed request DTOs there too.

=== Migration recipe (per endpoint)

*Create:*

* `XxxCreateRequest.java` — Jakarta-validated DTO
* `XxxCreateResponse.java` — plain POJO
* `XxxCreateCommand.java` — `extends Command<XxxCreateRequest>`
* `XxxCreateCommandHandler.java` — `@Component`, `@Retry`
* `XxxCreateCommandHandlerTest.java` — Mockito unit test

*Modify:*

* Service interface + impl — port business logic from `JsonCommand` to typed request
* `XxxApiResource` — wire endpoint to `dispatcher.dispatch(command).get()`
* `SecurityConfig` — add URL-level auth entry (end of chain)
* `application.properties` — add retry config
* `ValidationMessages.properties` — add error message keys

*Delete:*

* Legacy `NewCommandSourceHandler` for the endpoint
* Corresponding method in `CommandWrapperBuilder`
* Legacy `xxxService(JsonCommand)` signature on the service interface

=== Full example: Calendar CREATE

[source,java]
----
// 1. Request DTO with Jakarta validation at the API boundary
public class CalendarCreateRequest {
    @NotBlank private String    title;
    @NotNull  private LocalDate startDate;
    @NotNull  private Integer   typeId;
    @NotNull  private Integer   entityId;
}

// 2. Response POJO — no CommandProcessingResult
public class CalendarCreateResponse {
    private Long resourceId;
    private Long entityId;
    private String entityType;
}

// 3. Typed command
public class CalendarCreateCommand extends Command<CalendarCreateRequest> {
    private String entityType;
    private Long   entityId;
}

// 4. Handler
@Component
@RequiredArgsConstructor
public class CalendarCreateCommandHandler
        implements CommandHandler<CalendarCreateRequest, CalendarCreateResponse> {

    private final CalendarWritePlatformService service;

    @Override
    @Retry(name = "commandCalendarCreate")
    public CalendarCreateResponse handle(Command<CalendarCreateRequest> cmd) {
        CalendarCreateCommand c = (CalendarCreateCommand) cmd;
        return service.createCalendar(c.getEntityType(), c.getEntityId(), cmd.getPayload());
    }
}
----

*Wiring:* the API resource just builds the command, dispatches it, and returns the typed response. All the JSON serialization / audit-logging / `CommandWrapperBuilder` scaffolding is gone.

[source,java]
----
@POST @Path("/{entityId}/calendars")
public CalendarCreateResponse create(@Valid CalendarCreateRequest req,
                                      @PathParam("entityType") String entityType,
                                      @PathParam("entityId")   Long entityId) {
    CalendarCreateCommand cmd = new CalendarCreateCommand();
    cmd.setPayload(req);
    cmd.setEntityType(entityType);
    cmd.setEntityId(entityId);
    return dispatcher.dispatch(cmd).get();
}
----
