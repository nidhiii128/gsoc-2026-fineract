== Testing

Every handler ships with a Mockito unit test. Integration tests get updated when the Feign client regenerates.

=== Handler unit test pattern

[source,java]
----
@ExtendWith(MockitoExtension.class)
class CalendarCreateCommandHandlerTest {

    @Mock  CalendarWritePlatformService service;
    @InjectMocks CalendarCreateCommandHandler handler;

    @Test
    void delegatesToService() {
        var cmd = new CalendarCreateCommand();
        cmd.setEntityType("groups");
        cmd.setEntityId(1L);
        cmd.setPayload(new CalendarCreateRequest());

        handler.handle(cmd);

        verify(service).createCalendar(eq("groups"), eq(1L), any());
    }
}
----

The test proves dispatch semantics and service delegation without spinning up Spring context.

=== Integration tests

Fineract's integration tests exercise the auto-generated Feign client against a real database. When a migration changes an endpoint's response schema, the client changes, and the integration tests that call it need typed updates (usually a rename like `PostGroupsResponse → GroupCreateResponse`).

Alex's principle #8: no `HashMap` regression in these tests. Requests must go through the typed request DTOs.
