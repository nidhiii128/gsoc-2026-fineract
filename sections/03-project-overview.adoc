== Project Overview

*Parent ticket:* https://issues.apache.org/jira/browse/FINERACT-2169[FINERACT-2169 — New Command Processing Infrastructure] +
*Mentor:* Alex Vidakovic +
*Duration:* 12 weeks

The goal was to migrate legacy REST endpoints from Fineract's original `JsonCommand` command pattern to a new typed command framework — `Command<T>`, `CommandHandler<REQ, RES>`, `CommandDispatcher` — with Jakarta validation at the API boundary and URL-level authorization.

Each migrated endpoint was one pull request. Each PR had to satisfy Alex's eight architectural principles (see <<_implementation_walkthrough>>).
