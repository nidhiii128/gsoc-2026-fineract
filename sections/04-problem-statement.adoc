== The Problem

Historically, every Fineract write endpoint flowed through a class called `JsonCommand` — a string envelope carrying raw JSON:

[source]
----
REST  →  JsonCommand (string envelope)  →  Service.processCommand(cmd)
                                              ↓ (manual JSON parsing)
                                           CommandProcessingResult (generic)
----

Inside the service, JSON fields were extracted by string keys. Return type was always the generic `CommandProcessingResult`.

That worked, but at a cost:

* No compile-time type safety on request or response fields
* JSON parsing scattered across every service class
* Validation had to run at runtime, inside business logic
* Handler signatures told you nothing about their contract
* Auto-generated Feign client picked up weak types (`Object`, `Map<String, Object>`)
